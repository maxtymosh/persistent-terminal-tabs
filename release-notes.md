# Persistent Terminal Tabs 1.3.1

Keep your Claude and Codex terminal chats organized, then reopen VS Code and pick up where you left off. PTT saves chat groups, names, order and project folders. With tmux on macOS/Linux, it reconnects to live sessions after a VS Code reload or quit. After a reboot, recognized conversations resume through their agent CLI when saved history is available. Native Windows uses plain terminals without live reattachment.

This release adds a clearer README and installation guide, updates links to the transferred maxtymosh repository, and removes internal planning files from the installed package. Runtime behavior matches 1.3.0, including its searchable project-folder picker.

Download the `.vsix` and run **Extensions: Install from VSIX** in VS Code. Or download `ptt-install-bundle-1.3.1.zip`, extract it and give `install-prompt.md` to an AI coding assistant on your computer. Checksums are included. Marketplace publication is pending.
