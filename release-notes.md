# Persistent Terminal Tabs 1.5.2

Fixes the blank **Uncombine Group into Separate Tabs** button. It now uses VS Code's built-in overlapping-windows icon.

Includes new-user docking beside Terminal from 1.5.1 and Combine / Uncombine group actions from 1.5.0.

Download `persistent-terminal-tabs-1.5.2.vsix` and use **Extensions: Install from VSIX**. Restart extensions after installation to load the update. The `ptt-install-bundle-1.5.2.zip` includes the VSIX, installation prompt, README, status integration guide and checksums.

The replacement icon is verified against the installed VS Code icon registry. Marketplace submission still requires Microsoft publisher authentication.
